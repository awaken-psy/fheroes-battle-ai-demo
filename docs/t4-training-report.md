## 4. 分析

### 成功点

- **训练管线完整运行**：200k 步、所有 T2+T3 改进正常工作
- **example.json 达标**：88% 远超 50% 目标，证明 PPO 自博弈能学到有效策略
- **对手池活跃**：53.5% rollout 使用对手池，FIFO 淘汰正常
- **Entropy 下降**：3.63 → 2.63，策略在收敛而非随机游走
- **无 NaN/Inf**：全程数值稳定

### 未达标原因

| 配置 | 失败原因 |
|------|----------|
| even_clash.json | 非镜像阵容 + 英雄系统，训练从未见过英雄/非对称布局 |
| mage_duel.json | 法术决策，训练从未见过英雄施法机制 |
| dragon_battle.json | 高级兵种（龙/凤凰/骨龙）+ 宽体单位，训练只见过 Swordsman |

**根因**：单一配置训练导致 **零泛化**——agent 只学会了 example.json 的镜像近战，无法处理任何包含英雄、法术、高级兵种的场景。

### 改进建议

1. **多配置混合训练**：每局随机选一个配置（example/even_clash/mage_duel/dragon），让 agent 接触多样化场景
2. **更长的训练**：200k 步下 win rate 仍在震荡，可能需要 500k-1M 步
3. **学习率策略**：线性衰减导致后期几乎不学习，可尝试 cosine annealing 或 warm restart
4. **奖励塑形**：课程奖励的 phase 1 仅 10k 步（5%），对复杂配置可能太短

## 5. 结论

T4 训练战役证明了 **训练管线完全可用**，在训练配置上取得了 88% 胜率的优秀成绩。但单一配置训练的泛化能力不足，无法通过全部 benchmark。

**推荐下一步**：实现多配置混合训练（MILESTONES.md 可选扩展项），配合更长的训练步数（500k+），有望全面提升胜率。
